# FIXES

1. Event searches and results now skip the first event in each act's list. Every act opens on
its Ancient, and the game counts that as the act's first event, so the event listed first could
never actually appear. A seed found for an event in the first few now really offers it at one of
your first event rooms. This affected every earlier version, not only v2.0.0.
